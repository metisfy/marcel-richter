A metisCode project, part of the metisOne group. My role: concept and development.

## The project

For Kunstschmiede Bischoff we built a website that makes you want to try the craft – and behind it a dedicated admin area for shop, courses and dates. Visitors book forging courses such as the Damascus knife course directly online.

Website and admin area run in one container and are separated by address: kunstschmiede-bischoff.de for visitors, the admin area on its own subdomain.
