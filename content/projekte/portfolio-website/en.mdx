## Goals

- Lighthouse 95+ in every category
- Accessible to WCAG AA, light and dark theme
- Edit content without touching code

## Tech

The site is built with Next.js (App Router) and fully pre-rendered at build time. Projects,
photos and season info live as MDX and YAML files in the repository. Every push to `main` is
checked, built into a Docker image and deployed to the server automatically.
