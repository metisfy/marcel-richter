## Ziele

- Lighthouse 95+ in allen Kategorien
- Barrierefrei nach WCAG AA, helles und dunkles Design
- Inhalte pflegen, ohne Code anzufassen

## Technik

Die Seite ist mit Next.js (App Router) gebaut und wird beim Build vollständig statisch
erzeugt. Projekte, Fotos und Saison-Infos liegen als MDX- und YAML-Dateien im Repository.
Jeder Push auf `main` wird geprüft, als Docker-Image gebaut und automatisch auf den Server
ausgerollt.
